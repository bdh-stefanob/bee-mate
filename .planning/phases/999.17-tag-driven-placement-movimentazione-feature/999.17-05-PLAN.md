<objective>
Correggere il comportamento del Save dell'editor perché sia **intuitivo e senza bug**: oggi `handleSave` deriva SEMPRE il nome file dallo slug del titolo `Feature:`, quindi salvando un file esistente con titolo diverso dal nome crea un **duplicato** (e può sovrascrivere silenziosamente un file con quel nome). Ora che i tag sono la fonte di verità per la **cartella**, il **nome file** deve essere stabile (l'identità del file), e cambiare i tag deve **spostare** il file (non duplicarlo).

Purpose: il QA si aspetta che salvare un feature aperto aggiorni QUEL file; che cambiando i tag il file si sposti nel nodo giusto; e che non si creino duplicati né si sovrascriva nulla a sorpresa.
