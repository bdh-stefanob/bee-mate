<objective>
Implementare la **movimentazione via dialog**: un endpoint `POST /api/features/move` che sposta un `.feature` aggiornando i tag `@app @flow` nel contenuto (tag = fonte di verità), e un'azione "Sposta" nella pagina Features che riusa `FeaturePlacementDialog`.

Purpose: il QA deve poter riorganizzare i feature nell'albero. Poiché i tag determinano il path al Save, **spostare = riscrivere i tag + rilocare il file**; senza l'aggiornamento dei tag, il prossimo Save dall'editor riporterebbe il file alla vecchia posizione.

Output: endpoint move (rename + tag-rewrite + anti-overwrite + cleanup), bottone "Sposta" nella pagina Features, aggiornamento dei tab persistiti in localStorage.
</objective>

  <action>
Crea `web-ui/src/app/api/features/move/route.ts` (`POST`):
- Body: `{ fromPath: string, app: string, flow: string }` (fromPath relativo a src/features, es. `brochure-clinic/login/login.feature`).
- Valida: `safeFeaturePath(fromPath)` → `src` (404/403 se invalido o inesistente). `appSlug = slugify(app)`, `flowSlug = slugify(flow)` (400 se vuoti). `basename = path.basename(fromPath)`. `toRel = ${appSlug}/${flowSlug}/${basename}`; `safeFeaturePath(toRel)` → `dest` (403 se invalido).
- Anti-overwrite: se `dest` esiste ED è diverso da `src` → 409 `{ error: 'Esiste già un file in destinazione' }`.
- Esegui: leggi `content = fs.readFileSync(src)`; `updated = setFeatureTags(content, appSlug, flowSlug)`; `fs.mkdirSync(path.dirname(dest), { recursive: true })`; `fs.writeFileSync(dest, updated)`; se `dest !== src` → `fs.unlinkSync(src)`.
- Cleanup cartelle vuote: dopo unlink, risali da `path.dirname(src)` verso FEATURES_DIR rimuovendo le directory rimaste vuote (senza mai uscire da FEATURES_DIR; `fs.rmdirSync` solo se vuota).
- Ritorna `{ ok: true, path: toRelPOSIX }` (rel POSIX come fa /api/features). try/catch globale → `{ error }` 500.
  </action>

  </verify>
