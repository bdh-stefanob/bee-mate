# Phase 999.13 Plan 05: Import alberato dal bottone Features Summary

Il bottone "Carica .feature" della pagina Features ora apre un dialog di alberatura che chiede App + Flow (auto-suggeriti dai tag `@app @flow` del file con fallback al primo page marker, editabili, con autocomplete sui valori esistenti), salva verbatim in `src/features/{app}/{flow}/{file}.feature` e impedisce la sovrascrittura silenziosa di file esistenti.

## What Was Built

### Task 1 — Componente FeatureImportDialog (commit `e199af8`)

`web-ui/src/components/FeatureImportDialog.tsx` (nuovo, `'use client'`):
- **Auto-suggest:** deriva `app`/`flow` dalla tag line (`content.match(/^(@\S+(?:\s+@\S+)*)/m)`); fallback flow = `slugify(extractPageMarkers(content)[0]?.page)`.
- **Pagine rilevate:** sezione che elenca i `display` dei page marker estratti via `extractPageMarkers` (riuso lib Plan 03).
- **Autocomplete:** due `<input list>` con `<datalist>` popolati da `existingApps`/`existingFlows`.
- **Anteprima path:** `src/features/{slugify(app)}/{slugify(flow)}/{baseName}.feature` (estensione `.feature` garantita).
- **Guardia anti-overwrite:** confronto coda path normalizzata (rimozione prefissi `src/features/`/`features/`) contro `existingPaths`; se collisione → avviso giallo + checkbox di conferma obbligatoria, "Salva" disabilitato finché non spuntata.
- **Salvataggio verbatim:** `POST /api/features` con `{ content, filePath: targetRel }`, content non modificato; toast sonner per loading/errore; "Salva" disabilitato se `app`/`flow` slugificati sono vuoti.

`web-ui/src/lib/i18n.ts`: sezione `featureImport` aggiunta in `en` e `it` (title, appLabel, flowLabel, detectedPages, targetPath, overwriteWarning, overwriteConfirm, cancel, save, saving).

### Task 2 — Wiring nella pagina Features (commit `502b24b`)

`web-ui/src/app/features/page.tsx`:
- `handleFileUpload` non POSTa più flat (`filePath: file.name` rimosso): legge `file.text()`, salva `{ fileName, content }` in `importTarget` e apre il dialog (`setImportOpen(true)`).
- Calcolati `existingApps`/`existingFlows` (valori unici non vuoti da `f.app`/`f.flow`) ed `existingPaths` (`features.map(f => f.file)`).
- Render di `<FeatureImportDialog ... onSaved={p => { setImportOpen(false); toast.success(...); loadFeatures(); }} />`.
- Resto della pagina (tree, preview, openInEditor) invariato.
