### A) Preservazione tag originale (buildFeatureContent ~riga 370)

Prima:
```typescript

```

Dopo:
```typescript
const originalTagLine = feature.rawHeaderLines.find(l => l.trim().startsWith('@'));
if (originalTagLine) {
  lines.push(originalTagLine.trim());
} else {
  lines.push(`@${area}`);  // fallback per file senza tag
}
```

### B) Preservazione page marker / commenti (loop rawLines ~riga 405)

Prima: le righe `#PAGINA` cadevano nel ramo finale e venivano silenziosamente scartate.

Dopo:
```typescript
if (trimmed.startsWith('#')) {
  lines.push(`    ${trimmed}`);
  continue;
}
```

### C) Derivazione area robusta (~riga 254)

Prima:
```typescript
const area = areaArg ? slugify(areaArg) : slugify(feature.name) || slugify(inputBasename);
// slugify(inputBasename) produceva "import-1750857600000" con file temporanei
```

Dopo:
```typescript
const headerTagLine = feature.rawHeaderLines.find(l => l.trim().startsWith('@'));
const headerTags = headerTagLine
  ? (headerTagLine.trim().match(/@(\S+)/g) ?? []).map(s => slugify(s.slice(1)))
  : [];
const area = areaArg
  ? slugify(areaArg)
  : slugify(feature.name) || headerTags[1] || headerTags[0] || 'imported';
```
