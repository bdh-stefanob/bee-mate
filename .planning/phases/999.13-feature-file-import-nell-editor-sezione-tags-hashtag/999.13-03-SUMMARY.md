## What Was Built

### Task 1 — `extractPageMarkers` + `GET /api/tags`

- **`web-ui/src/lib/page-markers.ts`**: funzione pura `extractPageMarkers(content: string): PageMarkerCount[]` con la stessa logica `PAGE_MARKER_RE` di `_content.tsx`. Il marker è transitivo; le ripetizioni del medesimo marker vengono aggregate sommando `stepCount`. Normalizzazione: `toLowerCase().replace(/\s+/g, '-')`.
- **`web-ui/src/app/api/tags/route.ts`**: `GET /api/tags` scansiona tutti i `.feature` via `walkFeatures(FEATURES_DIR)`, aggrega le pagine in una `Map<slug, TagAggregate>` (somma `stepCount`, dedup `files`), ritorna `{ pages: TagAggregate[] }` ordinato per `stepCount` desc poi `page` asc. Nessun parametro path accettato dal client (T-999.13-01 mitigated).

### Task 2 — Pagina `/tags`, nav, i18n

- **`web-ui/src/app/tags/page.tsx`**: `'use client'`; fetcha `/api/tags` in `useEffect`; stato loading/error/empty/lista; per ogni pagina mostra `display`, badge `stepCount steps`, elenco file cliccabili. Click su file → `openInEditor` con pattern `gsd-editor-incoming` + `router.push('/editor')` identico a `features/page.tsx`. Stile Tailwind coerente con resto del portale (teal accents, card border-border).
- **`web-ui/src/app/layout.tsx`**: link `<Link href="/tags">Tags</Link>` aggiunto dopo Features e prima di `<NavSettingsLink />`.
- **`web-ui/src/lib/i18n.ts`**: aggiunto `nav.tags` (`en: 'Tags'`, `it: 'Tag'`) e nuova sezione `tags` con `title`, `stepCount`, `empty`, `files` in entrambe le lingue.
