**One-liner:** `.feature` drag-and-drop routed verbatim to a new editor tab via `onLoadFeature` prop and `openContentInNewTab` callback, bypassing the `.txt` import pipeline entirely.

## What Was Built

### Task 1 — ImportDropzone.tsx

Added optional prop `onLoadFeature?: (featureContent: string) => void` to `ImportDropzoneProps`. Modified `processFile` to branch on `.feature` extension **before** the existing `isExtendedFormat` / `/api/import` path:

- `.feature` → `file.text()` → `onLoadFeature(text)` (verbatim, zero transformations) + toast + `setState success`
- If `onLoadFeature` is absent → backward-compat fallback to `onImported(text)` (preserves other call sites)
- `.txt` → existing `isExtendedFormat` / `parseExtendedFormat` / `fetch('/api/import')` path unchanged

### Task 2 — _content.tsx

Added `openContentInNewTab` memoized callback after `handleOpenFile`:

```typescript
const openContentInNewTab = useCallback((fileContent: string) => {
  const tab = newTab(fileContent);   // label from Feature: line via labelFrom()
  setTabs(prev => [...prev, tab]);
  setActiveTabId(tab.id);
}, []);
```

Wired to `ImportDropzone`:

```tsx
<ImportDropzone
  onImported={featureContent => setContent(featureContent)}
  onLoadFeature={openContentInNewTab}
/>
```
