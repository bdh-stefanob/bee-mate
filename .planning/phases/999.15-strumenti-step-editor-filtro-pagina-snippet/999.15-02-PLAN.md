<objective>
Aggiungere sotto la search bar del pannello Steps una sezione **Snippet intent dichiarativi**: blocchi multi-step riusabili (es. "the user completes SMS verification") inseribili come singolo intent al cursore, in linea con lo standard BDD dichiarativo del progetto (Cucumber Book, vedi CLAUDE.md).

Purpose: spesso un sotto-flusso (verifica SMS, login standard…) è una sequenza di step sempre uguale. Avere snippet pronti riduce la digitazione e promuove la scrittura dichiarativa/intent invece dell'imperativo. La sorgente è un file statico nel repo che il team può estendere.

Output: file `step-snippets.ts` (libreria seed), sezione Snippet collassabile nello StepBrowser sotto la search bar (e sotto il filtro pagina del Plan 01), inserimento al cursore via `onInsert`, chiavi i18n. Include checkpoint di verifica visiva finale (filtro pagina + snippet).

NOTA: l'ultima task è un checkpoint `human-verify` → il piano è `autonomous: false`.
</objective>
