## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, chip gaps |
| sm | 8px | Input inner padding, button icon gap, compact row gaps |
| md | 16px | Card body padding, Settings field row spacing |
| lg | 24px | Section spacing within a page panel |
| xl | 32px | Major section gaps (Settings section → section) |
| 2xl | 48px | Page-level vertical rhythm |
| 3xl | 64px | (reserved; not used in this phase) |

Exceptions:
- Modal max-width: 672px (max-w-2xl) — matches existing StepDetailModal pattern
- Modal max-height: 90vh with overflow-y-auto — matches existing StepDetailModal
- CommitPreviewDialog width: max-w-md (448px) — narrower; confirmation-only content
- Touch/click target minimum: 44px height for all interactive buttons (WCAG 2.5.5)
- `space-y-2` (8px) for label + hint + input stacks — matches existing Settings page field() helper (inherited — not modified)

Source: `StepDetailModal.tsx` + `settings/page.tsx` (verified)

| Role | Light mode | Dark mode | Usage |
|------|-----------|-----------|-------|
| Dominant (60%) | oklch(0.985 0 0) = ~#FAFAFA | oklch(0.145 0 0) = ~#1A1A1A | Page background, editor background |
| Secondary (30%) | oklch(0.94 0.025 184) = light teal tint | oklch(0.205 0 0) = ~#282828 | Cards, Settings sections, modal background, sidebar |

| Orange accent | oklch(0.702 0.191 41.116) = orange-500 #F97316 | oklch(0.75 0.183 41.116) = orange-400 | Unknown-step underline in CodeMirror, "Proposed" badge |
| Destructive | oklch(0.577 0.245 27.325) = red-600 | oklch(0.704 0.191 22.216) = red-500 | Cancel push button, duplicate-proposal error toast only |

### Accent reserved for

- **Teal (primary):** "Propose step" confirm button, "Push to catalog" confirm button in CommitPreviewDialog, Settings "Saved" indicator text, focus ring on all inputs
- **Orange (#F97316 / --accent):** Unknown-step underline decoration in CodeMirror (`cm-unknown-step`), "Proposed" status badge background, the orange proposal panel below the editor (existing)
- **Destructive (red):** Cancel/dismiss in CommitPreviewDialog when abandoning a push, duplicate proposal error toast

### New visual element: "Proposed" badge

Status badge for `status: "proposed"` entries in Catalog and StepBrowser:
- Background: `oklch(0.702 0.191 41.116)` (--accent / orange-500)
- Text: white (`oklch(1 0 0)`)
- Style: `bg-[#F97316] text-white border-transparent` — same pattern as existing STATUS_STYLES in StepDetailModal

Existing STATUS_STYLES in `StepDetailModal.tsx`:
- `wanted` → `bg-[#FF6B2C] text-white` (orange variant)
- `implemented` → `bg-[#2ECC71] text-white` (green)
- `deprecated` → `bg-[#9CA3AF] text-white` (gray)
- **NEW** `proposed` → `bg-[#F97316] text-white border-transparent` (orange-500, slightly different from wanted)

### Unknown-step CodeMirror decoration

Class: `.cm-unknown-step`
Style: `border-bottom: 2px solid oklch(0.65 0.2 35)` (orange, consistent with --accent)
Light + dark: same orange value (matches existing `--cm-tag: #C2410C` pattern in dark already uses hue 35)

## Component Inventory

New components introduced in this phase. All reuse existing patterns.

### CommitPreviewDialog

Purpose: Confirm-before-push modal shown before every GitHub push (feature file or proposal).
Pattern: Same as StepDetailModal — fixed inset overlay, bg-black/50 backdrop, rounded-lg card.
Width: max-w-md (448px)
Structure:
- Header: "Committing as:" title + `font-mono text-sm` identity line
- Body: `commitName <commitEmail>` in monospace, branch name with teal chip
- Footer: two buttons — "Cancel" (ghost) + "Push" (teal primary)

### ProposeStepModal

Purpose: Step proposal form — opened from CodeMirror inline indicator.
Pattern: Same dimensions as StepDetailModal (max-w-2xl, max-h-90vh).
Structure:
- Header: expression pre-filled in `font-mono text-sm font-semibold`
- Body: keyword display (read-only badge), area Select dropdown (existing areas from catalog)
- Footer: "Cancel" (ghost) + "Propose step" (teal primary)

### Unknown-step inline indicator

Appearance: Orange underline (`cm-unknown-step` class) on step text that doesn't match catalog.
Interaction: Hover shows a CodeMirror tooltip with "Step not in catalog — click to propose".
Click target: The underlined text itself triggers the ProposeStepModal.
Non-blocking: Typing continues normally; no error state interruption.

### Settings — new fields

Three new fields added to the existing GitHub section pattern using the existing `field()` helper:
1. `catalogBranch` — text, default "catalog"
2. `commitName` — text, no default (empty placeholder)
3. `commitEmail` — text, no default (empty placeholder)

New sub-section "Commit identity" added between GitHub fields and Jira section:
- Section heading: same `text-base font-semibold border-b border-border pb-2` pattern
- PAT documentation block: `p` with `text-sm text-muted-foreground` + external link in teal

### "Proposed" badge in StepBrowser and Catalog

Badge component from `@/components/ui/badge` with custom className:
`bg-[#F97316] text-white border-transparent`
Positioned after existing status badge, same flex-wrap row.

## Interaction States

### CommitPreviewDialog

| State | Visual |
|-------|--------|
| Missing commitName/commitEmail | Warning block replaces identity line; "Push" button disabled |
| Ready to push | Identity line visible; "Push" button enabled (teal) |
| Pushing | "Push" button shows loading spinner, disabled; "Cancel" hidden |
| Push success | Dialog closes; sonner toast: success green "Pushed to {branch}" |
| Push error | Dialog stays open; sonner toast: error red with message |

### ProposeStepModal

| State | Visual |
|-------|--------|
| Pre-filled (expression + keyword) | Expression read-only in mono; keyword Badge read-only |
| Area not selected | "Propose step" button disabled; area Select shows placeholder "Select area…" |
| Area selected | "Propose step" button enabled (teal) |
| Submitting | Button shows spinner, disabled |
| Success | Modal closes; sonner toast: success "Step proposed — pushed to {branch}" |
| Duplicate | Modal stays open; inline error text below expression: red text-xs |

### Unknown-step highlight in CodeMirror

| State | Visual |
|-------|--------|
| Typing (debounced 300ms after last keystroke) | Orange underline appears on step lines not in catalog |
| Step added to catalog / proposals | Underline disappears on next catalog refresh |
| No catalog loaded (FS fallback) | Highlights based on local catalog; behavior unchanged |

### Settings fields (existing pattern, extended)

| State | Visual |
|-------|--------|
| Empty (commitName/commitEmail) | Input shows placeholder, no error state |
| Saved (on blur) | "Saved" text in emerald-600 fades after 2s |
| GitHub not configured | CommitPreviewDialog shows warning, push disabled |

## Accessibility Notes

- All modal dialogs: Escape key closes (existing pattern in StepDetailModal — verified)
- CommitPreviewDialog and ProposeStepModal: focus trap via `@base-ui/react` Dialog
- Orange underline on unknown steps: must not be the sole indicator (tooltip on hover required for color-blind users — WCAG 1.4.1 Use of Color)
- "Proposed" badge: text label "Proposed" present (not icon-only) — color not sole differentiator
- All interactive elements: minimum 44px touch/click target height (WCAG 2.5.5)
- Form inputs: each has an associated `<label>` element (existing `field()` helper pattern)
