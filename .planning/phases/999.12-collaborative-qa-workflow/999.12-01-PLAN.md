Create `web-ui/src/lib/github-utils.ts` exporting these functions (all use the GitHub REST API base `https://api.github.com`):

1. `export const GITHUB_NAME_RE = /^[a-zA-Z0-9_.\-]+$/;` — branch/owner/repo whitelist.

2. `export function ghHeaders(token: string): Record<string, string>` returning:
   ```typescript
   {
     'Authorization': `token ${token}`,
     'Accept': 'application/vnd.github+json',
     'X-GitHub-Api-Version': '2022-11-28',
     'Content-Type': 'application/json',
   }
   ```

3. `export async function getFileSHA(owner, repo, filePath, branch, token): Promise<string | undefined>`:
   - `GET https://api.github.com/repos/${owner}/${repo}/contents/${filePath}?ref=${branch}` with `ghHeaders(token)`.
   - 200 → return `((await res.json()) as { sha: string }).sha`.
   - 404 → return `undefined`.
   - else → `throw new Error(\`GitHub GET failed: ${res.status}\`)`.

4. `export async function getFileContent(owner, repo, filePath, branch, token): Promise<{ content: string; sha: string } | undefined>`:
   - Same GET; 200 → decode `Buffer.from(json.content, 'base64').toString('utf-8')` and return `{ content, sha: json.sha }`. 404 → `undefined`. else → throw.

5. `export async function putContents(owner, repo, filePath, branch, token, content: string, sha: string | undefined, message: string, author?: { name: string; email: string }): Promise<void>`:
   - Build body: `{ message, content: Buffer.from(content, 'utf-8').toString('base64'), branch }`.
   - `if (sha) body.sha = sha;`
   - `if (author) { body.author = author; body.committer = author; }`
   - `PUT https://api.github.com/repos/${owner}/${repo}/contents/${filePath}` with `ghHeaders(token)`, JSON body.
   - On non-ok: `throw new Error(((await res.json()) as { message?: string }).message ?? \`GitHub PUT failed: ${res.status}\`)`.

6. `export async function branchEnsure(owner, repo, branch, baseBranch: string, token): Promise<void>` (D-02):
   - `GET https://api.github.com/repos/${owner}/${repo}/git/ref/heads/${branch}` with `ghHeaders(token)`.
   - 200 → return (branch exists).
   - 404 → `GET https://api.github.com/repos/${owner}/${repo}/git/ref/heads/${baseBranch}`; read `json.object.sha` as baseSha; then `POST https://api.github.com/repos/${owner}/${repo}/git/refs` with body `{ ref: \`refs/heads/${branch}\`, sha: baseSha }`. Throw with the GitHub message on non-ok POST.
   - other status → throw.

7. `export function sanitizeError(message: string, token: string): string`:
   - `const escaped = token.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'); return message.replace(new RegExp(escaped, 'g'), '[TOKEN]');` (matches T-05-03-02).

Create `web-ui/src/lib/github-utils.test.ts` using Vitest. Mock `global.fetch` with `vi.fn()` in `beforeEach`; restore in `afterEach`. Cover the behaviors listed above. | Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
