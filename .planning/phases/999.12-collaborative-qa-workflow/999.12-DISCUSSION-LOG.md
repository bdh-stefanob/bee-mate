## Gestione Conflitti

| Option | Description | Selected |
|--------|-------------|----------|
| Fetch+merge ottimistico | Read SHA → add entry → push con SHA aggiornato | ✓ |
| Errore 409 + messaggio manuale | Push fallisce, l'utente riprova | |
| Last-write-wins | Sovrascrive senza controllare (pericoloso) | |

**User's choice:** Fetch+merge ottimistico  
**Notes:** L'utente ha prima chiesto "quanto spesso capita?" — discussione che ha portato alla conclusione che per un piccolo team le collisioni sono trascurabili, e il pattern fetch+SHA è già usato in `/api/github/push`.

| Option | Description | Selected |
